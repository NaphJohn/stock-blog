## K线图长什么样：阳线、阴线、实体、影线

- 一根K线 = 一个时间单位（日/周/分钟）的「开、高、低、收」四价。
- 阳线：收盘>开盘，A股通常红/空心；阴线：收盘<开盘，A股通常绿/实心。
- 实体 = 开盘到收盘的矩形；上影线 = 最高价到实体的细线；下影线 = 实体到最低价的细线。
- 实体越长代表当日单边力量越强；影线越长代表上方/下方抛压或承接越强。

## 单根K线的市场心理

- 光头光脚大阳线：一路买盘、多头控盘，常见于启动或主升。
- 大阴线：恐慌抛售或主力出逃，需结合位置（高位更危险）。
- 十字星：开收几乎相等，多空僵持，往往是变盘前兆。
- 长下影（锤子）说明低位有强承接；长上影则相反，高位出现是「上攻乏力」。

## 看涨/看跌吞没 与 十字星

- 看涨吞没：下跌末端大阳线实体完全包住前一根阴线 → 空转多信号。
- 看跌吞没：上涨末端大阴线包住前阳 → 多转空信号。
- 十字星出现在长期趋势末端，配合次日方向确认，胜率更高。
- 组合信号必须结合成交量与整体趋势，孤立一根意义有限。

## 锤子线、上吊线、早晨/黄昏之星

- 锤子线：低位长下影小实体 → 探底回升，偏多。
- 上吊线：高位长下影 → 看似企稳实则危险，需次日跌破确认。
- 早晨之星（三阴后阳）= 阴线→十字→阳线，底部反转；黄昏之星是顶部镜像。
- 这些形态在「关键支撑/压力位」附近出现最可靠。
