> 新手最常问的："市面上几十种指标，我该学哪些？"答案是：**学三类里各挑一个代表，组合用，别贪多**。

## 一、指标的三大类（先分类再挑）

| 类别 | 回答什么问题 | 代表指标 | 新手只学谁 |
|---|---|---|---|
| **趋势** | 现在的方向是涨是跌？ | 均线 MA、ADX、趋势线 | MA（5 / 20 / 60） |
| **动量 / 动能** | 这个方向有多强？是不是在减弱？ | MACD、RSI、KDJ、BOLL | MACD |
| **估值** | 现在贵不贵？ | PE、PB、PS、PEG、DCF | PE（重资产加 PB） |

学完这三类各 1 个 = 入门完毕。其它指标都是这三大类的"变体 / 补充"，等你真用顺了再学。

## 二、新手三件套建议

- **趋势：MA20 / MA60**（[kb09]）
- **动量：MACD**（[kb11] / [kb14]）
- **估值：PE（加 PB）**（[kb26] / [kb27]）

**三件套的角色**：
- 均线告诉你"大方向能不能做"（不在 MA60 上方就别重仓）；
- MACD 告诉你"动能变强还是变弱"（背离 = 预警）；
- PE / PB 告诉你"在这个位置买，划不划算"。

**三件都亮绿灯 = 较优；只亮 1-2 个 = 谨慎；三件都红灯 = 远离**。

## 三、组合使用三原则

1. **不同类指标互相印证**：均线 + MACD + PE 同时偏多 = 强信号；如果 MACD 金叉但 PE 在历史 90% 分位，要警惕高位接盘。
2. **同一类指标不要重复学**：MA + 趋势线 + ADX 都是看趋势的，学一个就够。
3. **指标用来"证伪 / 确认"，不预测**：你心里先有个判断（比如"这只跌多了，可能反弹"），再用指标去**确认**；别看到金叉就反推"要涨了"。

## 四、容易踩的坑

1. **指标越多越好？错**。3-4 个足够。堆 10 个指标只会让你"既想多又想空"。
2. **越复杂越准？错**。MACD 的本质就两条线 + 红绿柱；BOLL 就是中轨 ± 2 倍标准差。复杂的是包装，逻辑都是基础统计。
3. **指标能预测顶部 / 底部？错**。指标都是**滞后**的（基于历史价格算出来的）。它们的价值是**确认**趋势，**不是预测**。
4. **不同周期用同一套指标？错**。短线看 MA5 / MACD 日线；中线看 MA20 / 60 + 周线 MACD；长线看估值（PE / PB 分位）。

## 五、不同投资风格的"指标套餐"

| 风格 | 套餐 | 重点看 |
|---|---|---|
| **短线（数日）** | MA5 + MACD + 量能 | 金叉死叉、量价配合 |
| **波段（数周 - 数月）** | MA20 / 60 + MACD + PE 分位 | 趋势 + 估值底部 |
| **长线（年）** | MA250 + ROE + PE / PB 分位 | 价值与质地 |
| **定投（不择时）** | PE 分位 + 资产质量 | 便宜时多买，贵时少买 |
